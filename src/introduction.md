# 简介
Aitne 是一个原生为 MoonBit 生态构建的轻量级、高性能响应式 Web 框架。它通过 MBX——一种原生的、类似 JSX 的语法，为现代 Web 开发从底层设计而成——帮助开发者构建类型安全且高效的用户界面。

Aitne 深受 [Leptos](https://leptos.dev/) 和 [Solid](https://www.solidjs.com/) 等响应式框架的启发，摒弃了 Virtual DOM 所带来的额外开销。相反，它采用细粒度响应式机制，将模板直接编译为精确、高性能的 DOM 操作。

## 前置要求

，基本的浏览器 API
